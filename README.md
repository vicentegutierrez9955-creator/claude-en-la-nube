# claude-en-la-nube
web y productos digitales

## Maquetas de propuesta

| Cliente | Carpeta | Vista en línea |
|---|---|---|
| Hospital Veterinario San Agustín (Melipilla) | `veterinaria-san-agustin/` | https://plantillas-omega.vercel.app/veterinaria-san-agustin |
| Kine Rehabilita Sports (Melipilla) | `kine-rehabilita-sports/` | https://plantillas-omega.vercel.app/kine-rehabilita-sports |

Son páginas estáticas de una sola página (HTML + CSS, sin build). Llevan un aviso
de "maqueta de muestra" y `noindex` para que Google no las indexe antes de que el
cliente las apruebe. Los datos marcados en amarillo ("Foto y nombre", "Confirmar…")
hay que pedírselos al cliente.
